### 2. BankAccount.java
A bank account system with:

### 3. JDBCStudents.java
My first JDBC project - Connect Java with Database:
- Create Connection with DriverManager.getConnection
- Create table students with CREATE TABLE
- Insert student (Abrar, 24) with INSERT
- Get students with SELECT + ResultSet
- Example Output: id 1 name Abrar age 24
- Used try-catch / throws Exception for error handling
